Проєкт: ProMene

Як відкрити:
1. Розпакуйте ZIP-архів.
2. Відкрийте папку ProMene у Visual Studio.
3. Відкрийте файл ProMene.csproj (або через File -> Open -> Project/Solution).
4. Дочекайтеся відновлення залежностей.
5. Натисніть F5 або Ctrl+F5.

У браузері відкриється сторінка про мене.

Важливо:
- HTML повертає обробник MapGet("/") у Program.cs.
- CSS повертає окремий обробник MapGet("/style.css") у Program.cs.
- Фізичного файлу style.css у проєкті немає — це відповідає умові завдання.
- Проєкт використовує .NET 8.
